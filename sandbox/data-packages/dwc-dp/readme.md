## Darwin Core Data Package (DwC-DP)

DwC-DP is maintained by TDWG in [tdwg/rs.tdwg.org](https://github.com/tdwg/rs.tdwg.org/tree/master/dwc-dp) and published on rs.tdwg.org. The table schemas are not copied here: each version only has an `index.json` pointing to the table schemas on rs.tdwg.org, and a `version.json`. Changes to the schemas should be made upstream.

`index.json` is generated with [`sync-dwc-dp.py`](../../../sync-dwc-dp.py), see [Packages maintained elsewhere](../../../data-packages/readme.md#packages-maintained-elsewhere).

Versions:

- **1.0** (2026-10-13), table schemas at https://rs.tdwg.org/dwc-dp/1.0/

Earlier versions (0.1 and 1.0_DEV) are in [`sandbox/experimental/data-packages/dwc-dp`](../../experimental/data-packages/dwc-dp).
