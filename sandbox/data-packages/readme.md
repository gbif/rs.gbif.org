## Data Packages

This section contains sandbox versions of the data package schemas supported by the IPT, used by test IPTs.

The schemas are presented using [Frictionless Table Schema](https://specs.frictionlessdata.io/table-schema/) definitions.

DwC-DP schemas are maintained by TDWG in [tdwg/rs.tdwg.org](https://github.com/tdwg/rs.tdwg.org/tree/master/dwc-dp) and published on rs.tdwg.org. Only their `index.json` is here, pointing to the table schemas on rs.tdwg.org, so changes should be made upstream. See [Packages maintained elsewhere](../../data-packages/readme.md#packages-maintained-elsewhere).

See the [data packages readme](../../data-packages/readme.md) for how data packages are organised, versioned and released.
